# Handoff Workflow

At the end of a task, report:

## Summary
What behavior or issue was addressed.

## Files changed
List important files and why they changed.

## Verification
List commands/checks actually run and their outcomes. Mark checks not run or blocked.

## Integration status
For fullstack work, identify which layers are complete, which endpoints/contracts are real, and what remains mocked or TODO.

## Risks and remaining work
List known limitations, assumptions, unresolved errors, and follow-up actions.

Update `todo-list.md` to reflect actual status. Update `PROJECT-CONTEXT.md` when stack, architecture, important decisions, features, or integration state materially changes. Do not create verbose session logs for trivial work.
